## Verification principles
- Report the exact measurement window and the date metrics were collected.
- Distinguish merged PRs from opened, closed, or draft PRs.
- Exclude contributions to repositories you own when counting external contributions.
- Count unique external contributors, not PRs, for the community-builder criterion.
- Do not add private or confidential information.
- Clearly label estimates and third-party analytics.
